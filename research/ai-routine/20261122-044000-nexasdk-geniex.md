# Card refinement audit — NexaSDK / GenieX

Time: 2026-11-22 04:40 KST

## Sources checked
- https://github.com/qualcomm/GenieX (current official repository; old https://github.com/NexaAI/nexa-sdk returns HTTP 301 to this repository)
- https://geniex.aihub.qualcomm.com/en/get-started/what-is-geniex
- https://github.com/qualcomm/GenieX/releases (latest visible release v0.11.0, 2026-11-12)

## Fact check and changes
- Updated project name and canonical source to Qualcomm AI Hub GenieX; noted prior NexaSDK name based on the old repository URL redirect.
- Removed claims that Qualcomm merely invested in it, that it provides “Day-0” model support, and that it includes ASR/TTS/embedding/rerank. Current official sources reviewed do not substantiate these card claims.
- Corrected “NPU-first”: the official docs distinguish two routes. GGUF uses llama.cpp across CPU/GPU/Hexagon; Qualcomm AI Hub precompiled bundles use Qualcomm AI Engine Direct on NPU.
- Confirmed Android SDK for Kotlin/Java and sample Android app; Windows ARM64 and Linux ARM64 are also documented, but the runtime is Snapdragon-only.
- Added developer-preview caveat from the official docs, plus an interview response on model/runtime/device validation.
- Updated two related cards that had described NexaSDK as an unqualified NPU-first product; they now name GenieX and preserve the model-format/runtime distinction. Historical publication records were not rewritten.
- Attention signal checked live: repository page showed 8.5k GitHub stars and latest release v0.11.0 on Nov 12, 2026. Star count is volatile and is not used to support capability claims.

## Decision
Retain as an AI+Android integration card, recentered on the useful runtime/model-format distinction. Do not rank against Ollama, llama.cpp, or LM Studio without controlled evidence.

Confidence: high for documented project scope, runtime split, supported platforms and release; no independent device testing performed.

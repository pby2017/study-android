### 3. ML Kit GenAI quota and foreground restrictions

- Sources checked:
  - https://developers.google.com/ml-kit/genai
- Evidence:
  - Official docs say AICore enforces per-app inference quota.
  - Short-burst overload can return `ErrorCode.BUSY`.
  - Long-duration quota can return `ErrorCode.PER_APP_BATTERY_USE_QUOTA_EXCEEDED`.
  - GenAI inference is permitted only when the app is the top foreground application; background use can return `ErrorCode.BACKGROUND_USE_BLOCKED`.
- Popularity/adoption signal:
  - Official Google ML Kit GenAI docs for production Android on-device AI behavior.
- Decision: selected.
- Confidence: high.

### 4. Gemini Nano version retrieval and prompt quality evaluation

- Sources checked:
  - https://developers.google.com/ml-kit/genai
  - https://android-developers.googleblog.com/2026/05/android-ai-intelligence-system.html

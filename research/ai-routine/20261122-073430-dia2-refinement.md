## Fact-check

- README states the model can begin generating from the first words, offers 1B and 2B checkpoints, supports English, and caps generation at two minutes.
- README lists a separate Dia2 TTS Server under “Upcoming,” distinguishing the model's early generation from an available product streaming server.
- Quickstart says CUDA 12.8+ drivers are required for the documented setup, while the CLI selects CUDA when available and otherwise CPU. Thus “CUDA-only” would be inaccurate; CPU fallback does not establish Android runtime support.
- Repository presents Python installation/programmatic usage and does not document an Android SDK.
- Apache-2.0 applies to the project, but README notes third-party assets (including the Mimi codec) retain their own licenses.

## Change and decision

- Clarified CPU fallback and kept the boundary explicit: it is not proof of mobile support.
- Preserved the distinction between early generation and the not-yet-listed TTS server.
- Added the third-party asset license check and retained practical Android profiling guidance.
- No exact star count added to the public card because it is volatile and does not establish model quality.
- Confidence: high for claims explicitly stated in the README; Android integration feasibility remains unverified and is framed as work to validate, not as a supported feature.

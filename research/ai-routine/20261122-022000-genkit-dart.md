## Corrections and rationale

- Updated the old Preview framing to stable Genkit Dart 1.0 GA.
- Removed claims about `genkit_flutter_gemma` running Gemma 4 on-device and `genkit_foundation_models` bridging Apple Intelligence; the official current Dart 1.0 docs reviewed here do not substantiate those packages or claims.
- Replaced “move AI logic freely between client and server” with documented architecture choices: server flow via `defineRemoteAction`, model proxy via `defineRemoteModel`, and prototype/client-side calls with API-key risk.
- Clarified that provider plugins share an API surface but do not erase provider-specific authentication/model behavior.
- Marked agent/session APIs as experimental per the current API stability docs; kept the card focused on stable flows, schemas, remote calls, and security boundaries.

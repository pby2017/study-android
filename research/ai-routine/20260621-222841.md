## Candidates selected

### 1. Copilot Chronicle

- Source checked: https://github.blog/changelog/2026-06-02-gain-insights-across-your-agent-sessions-with-chronicle/
- Source type: official GitHub Changelog, published 2026-06-02.
- Evidence:
  - `/chronicle` turns Copilot session history into standup summaries, personalized tips, and custom instructions.
  - Coverage now includes sessions from Copilot cloud agent, Copilot code review, GitHub Copilot app, VS Code, and JetBrains.
  - Local sessions can sync to GitHub and appear in the repository Agents tab; sessions are private by default and can be shared view-only.
- Popularity/adoption signal:
  - Official Copilot CLI / GitHub agent-session memory feature spanning multiple mainstream developer surfaces.
- Selected reason:
  - Practical developer value: teaches teams to convert agent traces into reusable instructions and status context instead of treating chat history as disposable.
- Confidence: high.

### 2. Copilot CLI BYOK models

- Popularity/adoption signal:
  - Official Copilot CLI release for enterprise model governance and developer model routing.
- Selected reason:

- Confidence: high.

### 3. Enterprise-managed bypass permission controls

- Source checked: https://github.blog/changelog/2026-06-17-enterprise-managed-settings-now-support-bypass-permission-controls/
- Source type: official GitHub Changelog, published 2026-06-17.
- Evidence:
  - Enterprise admins can set `disableBypassPermissionsMode` to `disable` in enterprise-managed settings.
  - The setting prevents Copilot CLI and VS Code from automatically skipping permission prompts, also described as yolo mode or auto-approve.
  - GitHub says this is the first governance capability in enterprise-managed settings configuration; VS Code v1.122+ respects the policy.
- Popularity/adoption signal:
  - Official enterprise governance feature for GitHub Copilot clients.
- Selected reason:
  - Practical developer value: converts agent command approval from personal habit into centrally managed execution policy.
- Confidence: high.

### 4. Codex self-improving agent loop

- Source checked: https://openai.com/index/building-self-improving-tax-agents-with-codex/
- Source type: official OpenAI engineering case study, published 2026-05-27.
- Evidence:
  - OpenAI and Thrive describe a three-part loop: practitioner feedback, production traces, and Codex-driven eval iteration.
  - The Tax AI pilot processed 7,000 tax returns across participating Crete firms.
  - Reported outcomes include saving about one-third of preparation time, up to 97% accuracy, and about 50% throughput increase.
- Popularity/adoption signal:
  - Official production case study with domain practitioners, production traces, and measured outcomes.
- Selected reason:
  - Practical developer value: teaches how to turn production failures into eval-backed agent improvement rather than ad hoc prompt changes.
- Confidence: high for the reported claims; note that metrics are vendor-reported from an official case study.

## Signals

- `SWE-agent`
  - GitHub README shows MIT licensing and the current tool-using GitHub-issue fix flow.
  - Official docs say SWE-agent is still usable, but mini-swe-agent is the new recommended path and SWE-agent is a maintenance-only reference.
  - Live GitHub page shows 19.7k stars.
- `llama.cpp + GGUF`
  - README states the project goal is minimal-setup C/C++ inference across local/cloud hardware.
  - GGUF docs define GGUF as the inference file format for GGML executors.
  - quantize docs describe the two-phase convert-to-GGUF then quantize pipeline and mention imatrix plus Q4_K_M.
- `KnowU-Bench`
  - Project page and arXiv abstract both describe the benchmark as Android-emulation-based mobile-agent evaluation.
  - Public claims verified: 42 general GUI tasks, 86 personalized tasks, 64 proactive tasks, hidden user profiles, behavioral logs, LLM-driven user simulator, consent handling, post-rejection restraint, and hybrid rule-based + LLM-as-a-Judge verification.

## Selected

- Refined `SWE-agent` for clearer ACI wording and to make the maintenance-only / mini-swe-agent handoff more readable.
- Refined `llama.cpp + GGUF` to make the convert → quantize boundary and the GGUF file boundary explicit.
- Published `KnowU-Bench` as a new AI+Android card because it is current, educational, and supported by public benchmark sources.

## Rejected / Skipped

- Existing `Android Bench` card was not republished because the topic already exists in `_data/cards.yml` and the current card already covers the official Google benchmark cleanly.

Medium-high. The claims used here are directly supported by official project pages, GitHub READMEs, and the public benchmark page / arXiv abstract. Exact popularity numbers were only used where the source page exposed them live.

# Project KARL 카드 재검증

- 검토 시각: 2026-11-22 04:10 KST
- 결정: 기존의 “Android 온디바이스 AI 라이브러리” 홍보를 제거하고, AI 라이브러리 도입 전 README와 실제 플랫폼 타깃을 대조하는 검증 카드로 재구성.

## 출처 및 관심 신호

1. [Project KARL GitHub 저장소](https://github.com/theaniketraj/project-karl)
   - README는 “zero data egress”, 로컬 학습·추론·저장을 주장하고 Android/Compose/KMP 통합을 설명한다.
   - GitHub 검토 시점 공개 지표: 11 stars / 1 fork, 285 commits, 마지막 push 2025-10-06. 현재 관심·유지 신호는 낮고 신선하지 않다. 수치는 변동하므로 카드에서 생략.
   - LICENSE는 Apache-2.0.
2. 공개 소스를 shallow clone하여 Gradle과 runnable example을 대조했다.
   - `karl-core`, `karl-kldl`, `karl-room`, `karl-compose-ui` 빌드 파일은 각각 JVM 타깃을 선언하며 Android target 선언이 없다.
   - `karl-core`는 문서 주석에서 JVM 중심/향후 Android 확장을 설명한다. KLDL도 JVM 중심 및 Android 확장 계획을 명시한다.
   - `karl-room/src/androidMain`은 AndroidManifest만 있고 Kotlin 구현은 찾지 못했다.
   - 저장소의 runnable example은 `karl-example-desktop`이다. Android 앱 예제·배포 artifact는 검토한 저장소에서 찾지 못했다.
   - 출처: [core Gradle](https://github.com/theaniketraj/project-karl/blob/main/karl-core/build.gradle.kts), [KLDL Gradle](https://github.com/theaniketraj/project-karl/blob/main/karl-kldl/build.gradle.kts), [Room Gradle](https://github.com/theaniketraj/project-karl/blob/main/karl-room/build.gradle.kts), [Desktop example](https://github.com/theaniketraj/project-karl/tree/main/karl-example-desktop).

## 변경 판단

- 이전 카드의 온디바이스 학습·Android 적용 가능성이 현재 구현 상태로 확인되지 않아 제품 추천 문구를 제거했다.
- README의 zero-egress 문구는 upstream의 보안 보증으로 취급하지 않는다. 민감정보 처리가 요구되면 앱의 collector, persistence, logs, SDK/network paths를 실제 코드와 실행 환경에서 검증해야 한다.
- 도입 시 볼 evidence: Gradle target, platform source set, artifact publication, 실행 가능한 플랫폼 예제, 데이터 흐름.
- 인기·활동 신호가 약하므로 최신 인기 기술이라고 소개하지 않고, “마케팅 설명과 실제 Android 준비 상태를 검증하는 법”이라는 일반 개발자 교훈으로 유지.
- 중복 검사: AI SDK의 모델 기능을 소개하는 카드와 달리 이 항목은 플랫폼 타깃·artifact 검증 절차가 주제다. 보안·privacy absolute claims를 비판적으로 검증하는 학습 범위와 결합.
- Confidence: high (현재 저장소 파일과 Gradle 타깃을 직접 검사); 이후 upstream 변경 가능.

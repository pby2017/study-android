## Sources checked

- [Official MobileSAM repository README](https://github.com/ChaoningZhang/MobileSAM) — Tiny-ViT replacement, retained SAM pipeline intent, ONNX export, explicit CPU demo context, and model comparison table. GitHub displayed 5.9k stars at review; volatile interest signal, not evidence of Android readiness or model quality.
- [arXiv paper](https://arxiv.org/abs/2306.14289) — reports a single-GPU benchmark around 10ms (8ms encoder + 4ms decoder), a lightweight encoder 60x smaller than ViT-H, and CPU feasibility; “on par” is paper-level/model evaluation wording, not a device-wide guarantee.

## Corrections and rationale

- Removed “mobile에서 12ms” and “SAM 대비 5배 작고 7배 빠름” as unqualified statements. The cited 12ms timing is a single-GPU encoder+decoder measurement; README also reports about 3 seconds on its Mac i5 CPU demo.
- Kept the 5M encoder claim, but clarified that SAM's mask decoder remains and the full model is not simply 5M total parameters.
- Softened “100% compatibility” to matching/intended pipeline structure, not a guarantee across runtimes or deployment targets.
- Removed YOLO/Ultralytics integration claim because the original source set did not substantiate that deployment path.
- Added Android implementation questions: export/runtime operator compatibility, target-device end-to-end latency, memory, heat, and mask quality.

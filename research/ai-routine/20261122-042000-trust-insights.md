# Apple Trust Insights 카드 재검증

- 검토 시각: 2026-11-22 04:20 KST
- 결정: 공식 WWDC26 주제로 유지하되, 순수 온디바이스 분석이라는 인상을 없애고 네트워크·클라우드·피드백·결과 의미를 명시.

## 출처

1. [Apple Developer: Meet Trust Insights (WWDC26)](https://developer.apple.com/videos/play/wwdc2026/379/)
   - Apple 영상은 framework를 iOS 27에 도입한다고 설명하며, client-side Swift API와 entitlement, authorization, `InsightEvaluator` 사용을 제시한다.
   - `requestEvaluation`은 수 초 걸릴 수 있고 Internet reachability가 필요하다.
   - 시스템은 device + cloud infrastructure를 함께 사용한다. Device-sourced signals는 로컬 처리되고 inputs는 즉시 discard된다고 Apple은 설명하지만, 최종 output에는 Apple Account signal과 velocity check가 추가될 수 있다.
   - Apple은 interaction patterns, timing, context, basic sensor data를 사용하며 Photos/Messages/Mail의 content는 보지 않는다고 설명한다.
   - `IsLikelyBeingCoachedInsight`의 `unknown`은 위험이 낮다는 뜻이 아니라 “위험 근거 없음/판단할 신호 부족”으로 오해될 수 없다고 발표자가 분명히 경고한다.
   - 매 insight evaluation 요청의 `reportConsumption`은 mandatory이며, 누락 시 앱이 rate-limit될 수 있다.
   - Apple Business Register를 통한 사후 fraud label 제출은 선택 사항(필수 아님)이며 모델 개선에 도움을 준다.
   - 신호는 기존 risk logic의 보조로 써야 하며 sole factor/determinant가 아니고, trust insight만으로 outright blocking하는 것은 권장되지 않는다.
2. [Apple Developer: IsLikelyBeingCoachedInsight](https://developer.apple.com/documentation/trustinsights/islikelybeingcoachedinsight)
   - 해당 symbol의 공식 개발자 문서. 페이지 본문은 웹 도구에서 JavaScript 렌더링 제약이 있어 세부값은 WWDC transcript를 기준으로 교차 확인했다.
3. [Apple Newsroom: WWDC26 platform releases](https://www.apple.com/newsroom/2026/06/apple-unveils-next-generation-of-apple-intelligence-siri-ai-and-more/)
   - Apple이 iOS/iPadOS 27 세대를 WWDC26에서 발표한 사실을 확인.

## 교정 사항

- “온디바이스 ML 탐지” 단독 문구를 “기기 신호와 클라우드 모델을 결합한 평가”로 바꿨다. 기기 신호의 local processing과 network/server assessment는 다른 경계다.
- “Apple Business Register 오프라인 피드백”을 필수로 오해하지 않도록 바꿨다. 필수는 각 평가 직후 앱 반응을 보내는 `reportConsumption`; 사후 fraud label 제출은 선택 사항이다.
- `unknown`은 low-risk가 아니며, 신호를 단독 차단 기준으로 쓰지 말라는 통합 교훈을 추가했다.
- Privacy wording은 Apple의 발표/설명으로 귀속하고 보안 보증으로 확대하지 않았다. 검토 대상 앱의 전체 데이터 경로나 서버 저장 정책을 증명하는 것은 아니다.
- 인기도 신호: Apple 공식 WWDC26 영상과 symbol documentation 자체가 1차 출처. GitHub 별/외부 adoption metric 대상이 아닌 플랫폼 API 주제이므로 star 수를 적용하지 않는다.
- 중복 검사: 기존 Android scam/privacy cards와 겹칠 수 있으나, 이 카드는 구체적인 API integration의 mixed device/cloud architecture, `unknown` semantics, mandatory feedback contract가 고유 초점.
- Confidence: high (공식 영상 transcript 및 Apple release announcement).

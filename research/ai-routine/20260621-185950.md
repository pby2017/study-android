- Source checked: https://openai.com/index/the-next-evolution-of-the-agents-sdk/
- Source type: official OpenAI product post, published 2026-04-15.
- Evidence:
  - OpenAI describes updated Agents SDK support for agents that inspect files, run commands, edit code, and work in controlled sandbox environments.
  - The post lists configurable memory, sandbox-aware orchestration, Codex-like filesystem tools, MCP, skills, AGENTS.md, shell, and apply-patch style primitives.
  - Native sandbox execution supports bring-your-own sandbox or built-in providers including Blaxel, Cloudflare, Daytona, E2B, Modal, Runloop, and Vercel.
  - Manifest abstraction describes workspace inputs, outputs, local files, and storage mounts such as S3, GCS, Azure Blob, and R2.
  - Security section explicitly recommends separating harness and compute under prompt-injection and exfiltration assumptions.
- Popularity/adoption signal:
  - Official OpenAI release; availability says generally available to API customers.
  - Named sandbox ecosystem providers are listed.
- Selected reason:
  - High developer value: teaches agent runtime design and security boundary, not just SDK news.
- Confidence: high.

### 4. AI Edge Gallery MCP

- Source checked: https://developers.googleblog.com/a-smarter-google-ai-edge-gallery-mcp-integration-notifications-and-session-continuity/
- Source type: official Google Developers Blog, published 2026-05-19.
- Evidence:
  - Google AI Edge Gallery supports MCP over Streamable HTTP as an experimental Android feature.
  - App imports tool definitions and resource schemas into the on-device model's system prompt; Gemma 4 decides locally which tool is needed, then MCP server executes the request.
  - Developer tips recommend short MCP tool descriptions and bite-sized return snippets because on-device models have smaller context windows than server-side models.
  - Same post describes persistent chat history using LiteRT-LM fast prefill, with modern phone GPU prefill speeds exceeding 3,000 tokens/s.
- Popularity/adoption signal:
  - Official Google AI Edge Gallery update, Android app availability, Gemma 4/LiteRT-LM ecosystem signal.
- Selected reason:
  - Clear AI+Android angle: mobile on-device agent architecture with MCP tool schema and context-budget design.
- Confidence: high.

## Verified claims

- The README describes Driftx as a tool for AI agents to inspect and interact with apps running in iOS simulators and Android emulators. Commands include capture, inspect, tap/type/swipe, and screenshot/design comparison. Accessibility checks cover contrast, labels, and touch targets.
- Requirements explicitly include Metro running; Android requires ADB and a booted emulator. The platform table says physical devices are not yet supported. `.driftxrc.json` defaults to `react-native`. The package description says visual diff tool for Android, iOS, and React Native, but the README setup requires React Native/Metro; avoid interpreting the broad platform badge as generic native Android app support.
- The README documents agent integrations through CLI instructions for Claude Code, Cursor, Gemini CLI, Codex, or any shell-capable agent. Although GitHub tags the repository with `mcp`, the verified setup is CLI-based; removed the stronger claim that the project itself is an MCP server.
- `package.json` reports version 1.0.0 and MIT license. GitHub page displayed 7 stars, 1 fork, and 125 commits at review. The star/fork counts are volatile and show low adoption, not popularity; commit count indicates activity only.

- Reframed the card from an inaccurately labeled KMP/MCP testing framework to a React Native + AI-agent CLI example.

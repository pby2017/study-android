## 신규 후보 검토

### 선택: Gemini Live API on Android

- 분류: AI+Android
- 핵심 주장:
  - Android 앱은 Firebase AI Logic을 통해 Gemini Live API를 직접 호출해 실시간·저지연 음성 챗봇/에이전트 상호작용을 만들 수 있다.
  - Android 가이드는 `firebase-ai` 의존성, `RECORD_AUDIO` 권한, `LiveModel`, `gemini-2.5-flash-native-audio-preview-12-2025` 예시 모델을 제시한다.
  - Firebase AI Logic의 Live API 사용은 developer preview이며 비호환 변경과 제한 가능성이 있다.
- 소스:
  - https://developer.android.com/ai/gemini/live
  - https://firebase.google.com/docs/ai-logic/live-api
- 최신성/신호:
  - Android Developers 공식 가이드이며 Firebase 문서는 2026-06-18 UTC 업데이트.
  - Android 앱에서 백엔드 없이 실시간 음성 AI를 붙이는 교육 가치가 있고, pure Android가 아니라 AI+Android 개발 주제다.
- 중복 점검:
  - `_data/cards.yml`와 `auto-post-log.md`에서 `Gemini Live`, `Live API`, `native-audio`, `Firebase AI Logic.*Live` 검색.
  - 기존 Firebase AI Logic, ADK, AppFunctions, ML Kit GenAI 카드는 있었지만 Gemini Live API on Android 카드 없음.
- 선정 이유:
  - 실시간 음성 에이전트 UX, 세션 수명, 권한, 비용/쿼터, preview risk를 함께 다루는 Android AI 설계 주제.
- 신뢰도: 높음

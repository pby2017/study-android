# AgentStop 카드 재검토 — 2026-11-22 04:13 KST

## 후보 적합성과 주의점

- AgentStop은 AI 에이전트의 반복 추론을 측정하고 조기 종료하는 AI 시스템 연구라 프로젝트의 AI 주제 기준에 부합한다.
- AI+Android 실용 SDK로 소개하면 안 된다. 논문/공개 프로젝트의 주 평가 장비는 Apple M1 Max와 NVIDIA Jetson Orin AGX이며, README는 최소 24GB unified RAM을 요구한다. Android 앱 통합이나 휴대전화 실측은 확인되지 않았다.
- 웹 QA 경로는 Brave Search API를 사용한다. 모델 로컬 추론과 전체 workflow의 무외부통신/프라이버시 보장은 구분해야 한다. 논문 답변 평가용 Claude Haiku API는 공개 README에서 별도의 선택적 후처리로 설명한다.

## 확인한 출처와 근거

- ACM/Brave 공식 논문 PDF: https://brave.com/research/files/AgentStop.pdf
  - CAIS '26 논문. 실행 이력의 토큰 로그확률, 단계별 출력 토큰 수, 인접 단계 간 토큰 중복을 feature로 사용하고, agent/task/step 조합마다 XGBoost GBDT 분류기를 학습한다.
  - 분류기는 단계 종료 후 실행 여부를 예측한다. 성공 trajectory를 잘못 중단하면 완료율/utility가 떨어지므로 threshold는 효율·정확도 trade-off에 맞게 조정해야 한다.
  - 저자 보고치: FRAMES는 5단계 종료에서 낭비 에너지 약 22%, utility 하락 <2%; SimpleQA는 4단계에서 약 23%, <2%; Qwen3-Coder-30B-A3B + SWE-Bench Verified는 5단계에서 약 18~19% 절감, utility 하락 약 3% (blog 표기). 서로 다른 데이터셋·종료 단계 수치이므로 통합 평균 하나처럼 쓰지 않는다.
  - SWE-Bench Verified 기본 코딩 성공률은 500개 중 94개(18.8%)였고, 실패 run의 에너지 평균은 약 3004.6 mWh; 논문은 이 실험의 Bash-only harness를 설명한다.
- Brave 공식 발표: https://brave.com/blog/agentstop/
  - 연구를 ACM CAIS 2026 채택 논문이라고 밝히고 ACM Artifact Available, Functional, Results Reproduced 배지를 보고한다.
  - 벤치마크 상세/종료 단계별 절감과 utility 하락을 교차 확인했다. 통계는 Brave/저자 연구 결과이지 Android 성능 보증이 아니다.
- 공식 코드 저장소: https://github.com/brave-experiments/AgentStop/
  - MIT 라이선스, README가 M1 Max와 Jetson Orin AGX (각 64GB RAM) 검증을 명시하고 24GB unified RAM 이상을 요구한다. 실험 전체 재현에는 FRAMES 약 하루, SWE-Bench 약 5일이 들 수 있다고 안내한다.
  - 저장소에는 profiling scripts, experiment data, 재현 notebook이 있다. GitHub UI에서 18 stars, 0 forks, 2 commits; 저 adoption signal이며 paper acceptance/reproducibility badges와 별도로 기록한다.
- Zenodo data deposit: https://zenodo.org/records/20122255
  - version 0.1로 processed data와 94.9 MB 파일을 공개. 데이터 레코드의 별도 라이선스는 확인되지 않아 MIT를 데이터 라이선스라고 주장하지 않는다.
- ACM CAIS: https://www.caisconf.org/
  - 2026 program에 63개 peer-reviewed research paper와 46개 system demo를 명시. 논문의 conference status와 공식 채택 맥락을 확인하는 보조 출처.

## 카드 변경 결정

- 기존 “온디바이스 AI 에이전트 … 15~20% 에너지 회수” 단일 headline을 제거하고, 재사용 가능한 기술 학습(로그확률 + 출력 길이 + 단계 간 중복 → 작업·모델·단계별 classifier)으로 재구성.
- FRAMES/SimpleQA/SWE-Bench 결과와 조기 종료 단계별 수치를 분리해, 서로 다른 실험을 하나의 보편적 15~20% 약속처럼 보이지 않게 함.
- M1 Max/Jetson 평가 조건, Android 휴대전화 근거 부재, 웹 QA의 Brave Search API 경로를 적었다. 로컬 LLM 실행만으로 privacy/offline을 보장한다고 쓰지 않음.
- ACM CAIS 채택 및 artifact evaluation은 관심·재현성 신호로 기록하되, 18 GitHub stars를 인기/품질 증거로 과장하지 않음. 코드 MIT, 데이터 공개는 분리해 명시.

## 남은 검증 한계

- Android 기기에서 classifier/runtime을 배포하거나 전력 절감을 재현하지 않았다.
- 공개 repo는 2 commits뿐이고 장기간/다른 agent stack의 외부 채택은 입증되지 않았다. 연구 범위 밖의 agent, 모델, 사용 패턴에 수치를 일반화하지 않는다.

Confidence: high — 방법·수치·설치 장비·공개 artifact를 논문/공식 README/official post로 교차 확인. Android product applicability는 근거 없음.

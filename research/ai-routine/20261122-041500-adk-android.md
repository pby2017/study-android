# ADK Kotlin / Android 카드 재검증

- 검토 시각: 2026-11-22 (KST)
- 검토 대상: `ADK for Android — 클라우드와 Gemini Nano 에이전트를 앱 안에서 조합`
- 결정: AI+Android 주제로 유지하고, 현재 ADK Kotlin Android backend별 기능 차이를 중심으로 갱신.

## 출처와 관심 신호

1. [Google ADK Kotlin repository](https://github.com/google/adk-kotlin)
   - 현재 README는 Maven Central artifact 1.6.0과 Android model modules를 제시한다.
   - Backend matrix: LiteRT-LM은 on-device tool calling 지원, ML Kit `google-adk-kotlin-mlkit-android`는 beta이며 tool calling 미지원, Firebase AI는 cloud tool calling 지원.
   - 하나의 `LlmAgent` API에서 model backend를 교체할 수 있고 Android Compose 예제들이 제공된다.
   - GitHub 공개 페이지에서 검토 당시 309 stars / 57 forks 확인. 관심 signal일 뿐 품질·생산 준비 증거로 사용하지 않음.
2. [Android Developers: Build ADK agents for Android](https://developer.android.com/ai/adk)
   - Kotlin agent API, `google-adk-kotlin-core-android`, KSP processor, Gemini Nano의 ML Kit GenAI/`GenaiPrompt`, Firebase AI Logic 또는 backend key 보관 경로를 확인.
   - 이 문서는 dependency 예시가 0.1.0으로 남아 있어 최신 모듈 버전 근거로 쓰지 않았다. 현재 버전/지원표는 GitHub README 우선.
3. [Google Developers Blog: ADK for Kotlin and ADK for Android 0.1.0](https://developers.googleblog.com/adk-kotlin-android-building-ai-agents/)
   - 2026-05-21 발표 당시 ADK Kotlin과 Android 전용 라이브러리를 구분하고 hybrid orchestrator / on-device sub-agent 사용 사례를 설명.
4. [Google Developers Blog: ADK for Kotlin 1.0](https://developers.googleblog.com/announcing-adk-for-kotlin-10-building-production-ready-ai-agents-in-kotlin-android-and-beyond/)
   - 2026-09-09 Kotlin 1.0 GA 및 Android-first extensions를 발표. Core stable release와 Android ML Kit beta를 혼동하지 않도록 구분.

## 변경 판단

- 기존의 Kotlin/Java + cloud Gemini/ML Kit Gemini Nano 구도는 넓고 backend별 capability를 가렸다.
- 기능 선택에 중요한 차이(tool calling 지원 여부, beta 상태)를 카드 앞부분으로 이동.
- `LlmAgent` 공통 API를 강조하되, 모든 model backend가 같은 기능을 지원한다고 오해하지 않도록 함.
- API key는 앱에 포함하지 않는다는 경계와 모델·실기기 조건 검증을 면접 답변에 둠.
- 기존의 “민감한 하위 작업은 Gemini Nano로 분리”는 tool-calling 부재와 device support caveat를 숨길 수 있어 일반 권고로 쓰지 않음.
- `Google ADK Java·Go 1.0` 카드와 같은 ADK ecosystem이지만, 해당 카드는 server/JVM language releases 중심이고 이 카드는 Android model-backend capability 차이를 다루므로 병합하지 않음.
- 다음의 `OWASP MASVS-RESILIENCE + R8`은 AI가 핵심이 아닌 순수 Android 보안 주제라 routine scope에서 건너뛰고, 다음 AI 연계 주제 `ObjectBox`를 cursor 후보로 설정.
- Confidence: high. Star count는 volatile이며 카드에는 수치를 싣지 않음.

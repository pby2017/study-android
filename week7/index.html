7주차 발표 자료

AI 코딩 에이전트 도구 — 발표 확정 3개 주제. 각 덱은 개념·원리(코드/구조)·실측·설치까지 ~10장으로 설명합니다.

발표 확정 (3개 주제)

🔬 diagnose

AI에게 "체계적 디버깅"을 시키는 법 — 피드백 루프 6단계 규율. 이번 세션 실제 버그(div 균형 77/95 → +18) 진단 과정을 코드·숫자로.

📐 Spec Kit

명세가 코드를 만든다 — 스펙 주도 개발(SDD). constitution→specify→plan→tasks→implement 5단계. 설치·실습 흐름 + METR 근거.

🗺️ Understand-Anything

코드를 탐색 가능한 지식 그래프로 — tree-sitter(결정적)+LLM(시맨틱) 멀티에이전트 파이프라인. 2단계 분업·토큰 0 원칙·증분 업데이트까지 동작 원리 해부.
참고용 백업 덱 (발표 미포함)

📊 diagnose & Spec Kit (구 통합 덱)

위 두 주제를 한 파일로 합쳤던 이전 버전. 분리본(위)으로 대체됨 — 백업용.

🔄 handoff

대화를 인수인계 문서로 압축 → 다른 에이전트가 이어받기. mattpocock/skills, 무과금.

🛠️ skill-creator

스킬을 "측정 가능한 아티팩트"로 — eval·train/test 분할·벤치마크. anthropics/skills.

🧠 agentmemory

세션 넘어 기억하는 에이전트 메모리 — hooks 자동 캡처 + BM25·벡터·그래프 하이브리드 검색(RRF). 로컬 임베딩 무과금.

💡 슬라이드처럼 넘기기: 덱을 열고 ← / → 또는 Space로 한 장씩 전환. a 키 = 전체 스크롤(읽기) 모드 토글, n 키 = 발표자 노트 보기, Home/End = 처음/끝. 인쇄(Cmd+P)는 a로 스크롤 모드 전환 후 하면 전체가 이어서 출력됩니다.
